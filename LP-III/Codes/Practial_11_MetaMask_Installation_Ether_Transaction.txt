## BC-1: Install MetaMask and Study Ether Spent per Transaction

Aim: To install MetaMask and study the amount of Ether (ETH) spent during blockchain transactions.

### Requirements

- Google Chrome browser
- MetaMask extension
- Internet connection
- Ethereum test network

### Procedure

1. Open the official website: [https://metamask.io/](https://metamask.io/?utm_source=chatgpt.com)
2. Download and install the MetaMask browser extension.
3. Open MetaMask and select Create a New Wallet.
4. Set a password and securely save the Secret Recovery Phrase.
5. Select an Ethereum test network.
6. Obtain test ETH using an appropriate testnet faucet.
7. Send a small amount of test ETH to another test account.
8. Open the transaction details and observe the gas used and gas price.
9. Calculate the transaction fee.

### Formula

Transaction Fee = {Gas Used} x {Gas Price} 

For example:

- Gas Used = 21,000
- Gas Price = 10 Gwei

 = 21000 x 10 

 = 210000 Gwei

 = 0.00021 ETH

### Result

Thus, MetaMask was successfully installed, and Ether transaction fees were studied by calculating gas usage and gas price.

Precaution: Never share your private key or Secret Recovery Phrase. Use test ETH for this practical instead of real cryptocurrency.






What is MetaMask?

MetaMask is a cryptocurrency wallet that allows users to interact with Ethereum and other compatible blockchain networks.

What is Ether (ETH)?

Ether is the native cryptocurrency of the Ethereum blockchain.

What is Gas?

Gas is the unit used to measure the computational work required to execute a transaction on Ethereum.
